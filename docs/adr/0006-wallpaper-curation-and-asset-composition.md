# 0006. Curate Multi-Faction Panoramic Key Visuals and Portrait Agent Posters

We decided to curate the wallpaper asset pool with horizontal panoramic official Key Visuals (16:9 / 21:9) for desktop and vertical character showcase posters (9:16) for mobile devices, complemented by a canonical Inter-Knot / Bangboo iconographic identity. This prevents central readable text from colliding with close-up faces on desktop while delivering high visual impact on mobile screens.
