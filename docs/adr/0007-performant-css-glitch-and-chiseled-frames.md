# 0007. Implement Chiseled HUD Frames and Performant CSS-Only Micro-Interactions

We decided to implement the street industrial feel using lightweight, hardware-accelerated CSS effects (`Chiseled HUD Frame` with clip-paths/brackets, and subtle hover glitch/glow) rather than continuous heavy canvas CRT scanline overlays or audio SFX. This achieves the distinct Zenless Zone Zero aesthetic without degrading battery life, mobile framerate, or reader focus.
