# 0004. Replace Generic Mascot with Interactive Bangboo Widget

We decided to replace the default Spine model with an interactive Bangboo (邦布) assistant widget styled after New Eridu mascots (such as Eous / Amillion). The widget features customized dialogue bubbles in canonical Bangboo speech patterns ("En-nah!"), injecting thematic charm and humor while maintaining low runtime overhead compared to heavy skeletal animation models.
