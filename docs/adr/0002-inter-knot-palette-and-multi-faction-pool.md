# 0002. Adopt Classic Inter-Knot Palette with Multi-Faction Agent Wallpaper Pool

We decided to anchor the core UI theme in the canonical Inter-Knot street palette (Void Black `#121316` and Acid Yellow `#F6EE24`), while populating the wallpaper and visual assets with a multi-faction rotation of popular agents (Cunning Hares, Victoria Housekeeping, Section 6, Sons of Calydon, etc.). This ensures unified high-contrast legibility across all UI elements while offering rich visual variety and celebrating the diverse cast of Zenless Zone Zero.
