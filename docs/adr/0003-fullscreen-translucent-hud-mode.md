# 0003. Adopt Fullscreen Immersive Wallpaper with Translucent HUD Overlay

We decided to configure the site background in fullscreen wallpaper mode with dark acrylic blur overlays (`Translucent HUD Overlay`). Rather than restricting visual richness to a static top banner, fullscreen agent artwork immerses the visitor into the New Eridu terminal aesthetic. Legibility is preserved by enforcing darkened, blurred container surfaces with crisp acid-yellow borders.
