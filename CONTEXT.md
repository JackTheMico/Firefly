# ZZZ Theme Context

Domain concepts and ubiquitous language for the Zenless Zone Zero (绝区零) visual and architectural theme transformation of the Firefly blog.

## Language

**Inter-Knot Palette (绳网标准配色)**:
The primary high-contrast color scheme comprising Void Black (`#121316`), Acid Fluorescent Yellow (`#F6EE24`), Alert Hazard Orange (`#FF5522`), and High-Contrast Industrial White/Gray.
_Avoid_: Brand color, generic dark mode

**Agent Roster Wallpaper Pool (代理人轮播壁纸库)**:
A multi-faction collection of high-resolution key visual wallpapers and artwork (spanning Cunning Hares, Victoria Housekeeping, Section 6, and Sons of Calydon) rotating across desktop and mobile views.
_Avoid_: Random wallpaper, background images

**Translucent HUD Overlay (半透明 HUD 悬浮层)**:
Dark acrylic blurred panels with chiseled borders layered over fullscreen agent wallpapers to maintain terminal immersion alongside reading legibility.
_Avoid_: Solid cards, transparent background

**Chiseled HUD Frame (斜切角 HUD 线框)**:
The geometric UI container style utilizing angular corner clips, fluorescent acid borders, brackets, and hazard diagonal stripes.
_Avoid_: Generic rounded card, box border

**Hardware-Accelerated Street Glitch (硬件加速街头微动效)**:
Restrained, performant CSS-only hover micro-interactions (subtle chromatic aberration and neon yellow glow) with zero persistent CPU drain.
_Avoid_: Heavy canvas scanlines, screen noise loop

**Proxy Terminal Identity (绳网终端身份)**:
The thematic hybrid branding uniting the author's personal identity ("摸鱼岛 / 摸鱼侠") with Inter-Knot proxy nomenclature (e.g. `PROXY LICENSE`, `SECTOR //`, `RECORD ARCHIVE`).
_Avoid_: Generic blog metadata, full in-universe fiction

**Inter-Knot Commission (绳网委托)**:
The domain metaphor representing blog posts and dynamic feeds, characterized by commission grade tags, client metadata, and warning/tech badges.
_Avoid_: Blog post, article item

**Proxy License (绳匠身份卡)**:
The domain metaphor representing the author's profile and sidebar widget, styled as an authorized hollow investigator/proxy ID card.
_Avoid_: User profile, author card, bio

**Acid Industrial Aesthetic (酸性重工视觉)**:
The core design language derived from Zenless Zone Zero, featuring deep pitch black, high-visibility fluorescent yellow/acid green accents, chiseled angular borders, hazard diagonal striping, and subtle CRT scanlines.
_Avoid_: Flat design, minimal pastel, standard modern UI

**Bangboo Widget (邦布挂件)**:
The domain metaphor for interactive assistant widgets or companion elements, replacing generic mascot/pet widgets with New Eridu Bangboo styling.
_Avoid_: Live2D mascot, pet widget
